# Upper-left stacked brand concept

Visual study requested 2026-09-22: actual traced tree with Iron, Pine and Outdoors on separate lines to its right. Text steps outward with the branches. Tree height 18 mm, tip 3 mm from top, center X14 mm; text size 4 mm. Mounting-hole centers, 8 mm P504 aperture and ARM/PULL centers follow N1.4. Caps are schematic front outlines. Arial typography is a visual approximation of the production Liberation Sans font; this is not a manufacturing export or print-quality validation.

[Full faceplate](faceplate.png) / [Logo detail](logo_detail.png). Editable SVGs accompany both images. Regenerate with `python -B mechanical/enclosure/preview_stacked_brand.py` (PyMuPDF required).

N1.4 production SCAD/STLs and print recommendations remain unchanged pending visual feedback.
